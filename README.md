# EduCompiler

Interactive Compiler Learning and Visualization System: an academic project that helps
Software Engineering students understand how compilers work.

## Status

Phase 1 complete: project foundation (React + Vite client, Express + TypeScript server).

## Run locally

```bash
# Terminal 1
cd server && npm install && npm run dev

# Terminal 2
cd client && npm install && npm run dev
```

- Client: http://localhost:5173
- API health check: http://localhost:5000/api/health

Copy `.env.example` to `.env` in both `client/` and `server/` first.
